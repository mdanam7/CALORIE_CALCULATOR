# CALORIE_CALCULATOR
CalorieX <br>
CalorieX is a modern calorie tracking web app built with pure HTML, CSS, and JavaScript.<br>
It helps users monitor daily calorie intake with a clean UI, smooth animations, and simple progress tracking.<br>

Designed for students, beginners, and anyone trying to stay mindful about their eating habits without using complicated fitness apps.<br>

✨ Features<br>
=User Signup & Login<br>
=Daily calorie tracking<br>
=Progress bar visualization<br>
=Smart calorie feedback system<br>
=Entry history log<br>
=Responsive modern UI<br>
=Animated interactions<br>
=Dark theme design<br>
🛠️ Built With<br>
=HTML5<br>
=CSS3<br>
=Vanilla JavaScript<br>
=Tabler Icons<br>
🎯 Why I Built This<br>
<br>
--Most calorie tracker apps feel cluttered and overwhelming.<br>
I wanted to create something lightweight, visually clean, and beginner-friendly while practicing frontend development and DOM manipulation.<br>
