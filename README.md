# CALORIE_CALCULATOR
CalorieX
CalorieX is a modern calorie tracking web app built with pure HTML, CSS, and JavaScript.
It helps users monitor daily calorie intake with a clean UI, smooth animations, and simple progress tracking.

Designed for students, beginners, and anyone trying to stay mindful about their eating habits without using complicated fitness apps.

✨ Features
=User Signup & Login
=Daily calorie tracking
=Progress bar visualization
=Smart calorie feedback system
=Entry history log
=Responsive modern UI
=Animated interactions
=Dark theme design
🛠️ Built With
=HTML5
=CSS3
=Vanilla JavaScript
=Tabler Icons
🎯 Why I Built This

--Most calorie tracker apps feel cluttered and overwhelming.
I wanted to create something lightweight, visually clean, and beginner-friendly while practicing frontend development and DOM manipulation.
